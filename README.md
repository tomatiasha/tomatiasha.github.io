# Toma — Motion Portfolio

A slide-based, scroll-free portfolio starter for architecture, landscape, art, and animation. Built with plain HTML, CSS, and JavaScript; no frameworks, paid plugins, subscriptions, or build step.

## Preview
Open `index.html` in a modern browser. The site uses click-through sections, animated transitions, a navigation index, keyboard arrow navigation, and project detail overlays. On phones, the project gallery can scroll inside its slide so it remains usable.

## Replace sample project images
Add images to `assets/projects/` with these names:
- `project-01.jpg` through `project-05.jpg`

If images are not added yet, the page shows styled abstract placeholders. Use JPG, PNG, or WebP; if you use a different extension, update the image path in `index.html` and `script.js`.

## Personalize the text
Edit `index.html` for section text, project card labels, your About section, résumé link, and email address. Edit the `projects` array in `script.js` for each project detail overlay (title, category, year, image, description).

Before publishing:
- Replace `your.email@example.com` with your email.
- Add your résumé PDF at `assets/Toma-Resume.pdf`.
- Replace project descriptions and add only images/media you have permission to publish.

## Publish free on GitHub Pages
This is a replacement design for the same repository `tomatiasha/tomatiasha.github.io`.

1. Unzip this package.
2. Open your existing repository: https://github.com/tomatiasha/tomatiasha.github.io
3. Click **Add file → Upload files**.
4. Upload the new `index.html`, `styles.css`, and `script.js` from this package. If GitHub asks about overwriting existing files, confirm you want to replace them.
5. Upload the `assets` folder if you have added images; the included starter can run without it.
6. Click **Commit changes**.
7. Wait a few minutes and open https://tomatiasha.github.io.

You do not need to change Custom domain or Pages settings if the current site is already published.

Official guide: https://docs.github.com/en/pages/quickstart
