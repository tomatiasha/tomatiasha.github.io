# Toma — Portfolio Website

A responsive, editorial portfolio starter for architecture, landscape, art, and animation. It uses plain HTML, CSS, and JavaScript—no paid theme, framework, subscription, or build tools.

## Preview locally

1. Unzip this folder.
2. Open `index.html` in Chrome, Firefox, Edge, or Safari.
3. To publish it online, follow the GitHub Pages steps below.

## Add your work

Put your own images in `assets/projects/` and use these exact filenames to replace the placeholders:

- `hero.jpg` — wide hero image
- `project-01.jpg` through `project-06.jpg` — project card images

JPG, PNG, and WebP are all fine; if you use another format, update the matching image path in `index.html`. For crisp loading, resize images to roughly 1600–2200 px on the long edge and compress them before uploading.

Open `index.html` in a text editor to update:
- Your name/wordmark and introduction
- Project titles, years, categories, and descriptions
- About section
- Contact email (`your.email@example.com`)
- Résumé link (`assets/Toma-Resume.pdf`)

The category filters use each card's `data-category` value. Keep it as one of `architecture`, `landscape`, `art`, or `animation`.

## Publish free with GitHub Pages

You need a free GitHub account. A custom domain is optional and is not needed.

1. Go to https://github.com and create/sign in to a free account.
2. Click **New repository**. Name it exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Set the repository to **Public** and create it.
4. Open the repository, choose **Add file → Upload files**, and upload the contents of this folder—not the outer folder itself. Make sure `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder appear at the repository root.
5. Click **Commit changes**.
6. Open the repository's **Settings → Pages**. If asked for a source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io`. Refresh the Pages screen if it has not appeared yet.

GitHub's interface may change slightly. Their official guide is https://docs.github.com/en/pages/quickstart.

## Before you share it

- Replace all sample titles and descriptions with your real work.
- Add your images and résumé PDF.
- Replace the placeholder email address.
- Check the site on a phone and desktop.
- Use only images, fonts, and media you have permission to publish.
